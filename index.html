📱 Cara Install Aplikasi

🤖 Untuk Android (Chrome)

  • 1Buka aplikasi ini di Google Chrome
  • 2Ketuk titik tiga ⋮ di pojok kanan atas browser
  • 3Pilih "Add to Home screen" atau "Install app"
  • 4Ketuk "Add" untuk konfirmasi
  • 5Ikon 🏪 akan muncul di layar utama HP Anda!

🍎 Untuk iPhone/iPad (Safari)

  • 1Buka aplikasi ini di Safari (bukan Chrome)
  • 2Ketuk ikon Share (kotak dengan panah ke atas) di bawah
  • 3Scroll ke bawah, pilih "Add to Home Screen"
  • 4Ketuk "Add" di pojok kanan atas
  • 5Aplikasi siap dipakai seperti aplikasi native!

💻 Untuk Komputer (Chrome/Edge)

  • 1Buka aplikasi ini di Chrome atau Edge
  • 2Klik ikon 📥 Install di kanan address bar
  • 3Atau klik titik tiga ⋮ → "Install Aplikasi"
  • 4Klik "Install" di dialog yang muncul
  • 5Aplikasi akan muncul di desktop/start menu!
